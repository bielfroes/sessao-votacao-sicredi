# Sistema de votação de assembleias

Backend REST para cadastrar associados e pautas, abrir sessões de votação, registrar um voto por associado em cada pauta e consultar resultados.

## Documentação

Consulte o [guia técnico e de execução](assembly/README.md) e as [decisões de arquitetura](assembly/docs/architecture-decisions.md). Com a aplicação em execução, a documentação OpenAPI fica disponível em `http://localhost:8080/swagger-ui/index.html`.
